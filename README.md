# LA Spots

Карта мест в Лос-Анджелесе: где поиграть, что посмотреть и где сделать фото для Instagram.

## Как добавить или изменить места

1. Открой сайт, нажми **✏️ Редактор**.
2. **📍 Точка** — клик по карте; **⬠ Область** — обведи место точками и нажми «Готово».
3. Правки сразу сохраняются в твоём браузере. Чтобы они появились на сайте у всех:
   нажми **⬇ Копия** → на GitHub открой репозиторий → **Add file → Upload files** → перетащи скачанный `data.js` → **Commit changes**.
   Через минуту сайт обновится.

## Файлы

- `data.js` — все места на карте
- `config.js` — название сайта, категории, цвета
- `app.js`, `styles.css`, `index.html` — сам сайт
- `supabase-setup.sql` — на будущее, для редактора с паролем
